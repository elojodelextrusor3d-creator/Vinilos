Mis llaveros

Cada link que copiás se guarda acá, en este teléfono. Si editás uno, después volvé a grabar ese llavero.

En NFC Tools: Escribir → Agregar un registro → URL / URI → elegí el prefijo https:// → pegá lo copiado → Escribir → acercá el llavero.

Portada personalizada: descargá la portada y subila a GitHub (repositorio Vinilos → Add file → Upload files), junto al index.html, sin cambiarle el nombre. Hasta que la subas, el vinilo se ve sin ella.

Solo funciona con playlists (no álbumes ni canciones sueltas).
